# Mijn Webshop

Een moderne, responsieve webshop gebouwd met PHP, CSS en JavaScript.

## Functies

- **Productbeheer**: Uitgebreide lijst met producten, inclusief prijzen, categorieën en nu ook voorraadinformatie.
- **Modern Navigatie-ontwerp**: Vernieuwde header met een interactief winkelmandje dat real-time updates toont.
- **Dynamische Slideshow**: Een aantrekkelijke hero-slideshow op de homepagina met de meest populaire producten.
- **Filterfunctionaliteit**: Gebruiksvriendelijke filters op de productpagina voor categorie en maximale prijs.
- **Winkelmandje & Afrekenen**: Volledig functioneel winkelwagentje en een afrekenproces inclusief e-mailbevestiging.

## Recente Updates

- **Voorraadbeheer**: Producten hebben nu een `stock` eigenschap.
- **Voorraadindicatoren**: Productkaarten tonen nu de actuele voorraad, inclusief een "Lage Voorraad" waarschuwing bij minder dan 20 items.
- **Gepolijste UI**: Verbeterde lay-outconsistentie en visuele verbeteringen in de gehele shop.
- **Code Optimalisatie**: Verbeterde code-architectuur voor betere compatibiliteit en stabiliteit.

## Installatie

1. Kloon deze repository naar je lokale webserver.
2. Zorg dat PHP is geïnstalleerd.
3. Open `index.php` in je browser om de shop te verkennen.
